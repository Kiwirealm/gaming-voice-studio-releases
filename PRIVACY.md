# Privacy and network use

Clips processes imported recordings and music on your computer. The app does
not upload videos, voice samples, projects or usage telemetry.

The first Setup downloads FFmpeg/ffprobe from Gyan's upstream build site and
checks the archive checksum. An installation with an update source checks
GitHub Releases for new versions. GitHub and download providers receive the
normal network information involved in an HTTPS request, including your IP
address. Automatic update checks can be disabled in Help; downloading an
installer is a separate user action. Editing works without those requests.

Settings, recovery files, logs and update downloads are stored locally under
the user's GamingVoiceStudio application-data folder. Saved project files
reference the paths of your original media; consider those paths before
sharing a project or diagnostic file yourself.
